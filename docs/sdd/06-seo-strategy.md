# SEO Strategy

- SSR + prerender for all public routes.
- Per-page title/description/OG/Twitter cards via Angular Meta service.
- Structured data: Organization, LocalBusiness, Service, WebSite (JSON-LD).
- `sitemap.xml` (multilingual with hreflang), `robots.txt`.
- Canonical URLs; hreflang for ES/EN.
- Image optimization (WebP, lazy load, alt text).
- Core Web Vitals targets: LCP<2.5s, CLS<0.1, INP<200ms.
- Internal linking between units; blog optional (phase 2).
- Google Search Console + Bing Webmaster Tools submission.
- Meta Pixel + Conversions API (cookie-consented).
