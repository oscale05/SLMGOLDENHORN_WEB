# Meta Compliance Checklist

Source docs: `POLÍTICA DE PRIVACIDAD DE SLM GOLDEN HORN SRL.docx`, `POLÍTICA DE COOKIES DE SLM GOLDEN HORN SRL.docx`, `Documento.docx` (T&C).

Public URLs required:
- https://slmgoldenhorn.com/privacidad
- https://slmgoldenhorn.com/cookies
- https://slmgoldenhorn.com/terminos
- https://slmgoldenhorn.com/data-deletion (instructions)

App Review requirements:
- [ ] Privacy Policy URL accessible without login
- [ ] Terms URL accessible
- [ ] Data Deletion Callback URL (`/api/v1/meta/data-deletion`) responding
- [ ] User Data Deletion Instructions page
- [ ] Domain verified in Meta Business Manager
- [ ] HTTPS with valid cert
- [ ] App icon, description, screencasts of permissions
- [ ] No sale of Meta user data; no training on personal data (per privacy policy §5)
- [ ] Opt-in/opt-out flows documented

Cross-reference: privacy policy §9 (data deletion), T&C §2-4 (Meta usage).
